# Data Structures Operations

Three separate Python programs demonstrating basic operations on:

1. **Array** (`array_operations.py`)
2. **Stack** (`stack_operations.py`)
3. **Queue** (`queue_operations.py`)

## How to Run

Make sure you have Python 3 installed.

```bash
# Array operations
python array_operations.py

# Stack operations
python stack_operations.py

# Queue operations
python queue_operations.py
```

Each program provides an interactive menu to perform the respective operations.

## Features

### Array Operations
- Create / Initialize
- Insert (at position or append)
- Delete (by value or index)
- Search
- Update
- Display
- Sort
- Reverse
- Get length

### Stack Operations (LIFO)
- Push
- Pop
- Peek (top)
- Display
- Check empty
- Size

### Queue Operations (FIFO)
- Enqueue
- Dequeue
- Front (peek)
- Display
- Check empty
- Size
